# قائمة مهام ظهور موقع محفوظ في البحث

الرابط الرسمي: https://mahfouz-coaching.pages.dev/

آخر فحص مباشر: ١٨ نوفمبر ٢٠٢٦. اقرأ [تقرير الفحص وخريطة الكلمات](SEARCH_VISIBILITY_AUDIT_2026-11-18.md) قبل استكمال العمل. ظهور الرابط في أداة Web Search لا يثبت فهرسته في Google أو ترشيحه تلقائيًا في منصات الذكاء الاصطناعي.

خطة التنفيذ القادمة ومعايير إغلاق البنود: [خطة جاهزية SEO وGEO](SEO_GEO_READINESS_PLAN.md). ابدأ بالدفعة R01–R03، ثم تابع باقي الفحوص أثناء انتظار الفهرسة. البنود التاريخية أدناه ليست بديلًا عن قائمة القبول الشاملة.

## الفهرسة

- [x] إجراء اختبار أولي لجوجل في مصر ولقائمة الترشيحات على ChatGPT وClaude وGemini يوم ١٥ نوفمبر ٢٠٢٦. رابط الموقع غاب عن العينات التي اختبرناها.
- [x] التأكد من أن نسختي الموقع تفتحان وأن روابط اللغة وملف الزحف وخريطة الموقع متاحة على النطاق المنشور.
- [x] بدء تسجيل رابط الموقع في Google Search Console وتحضير ملف إثبات الملكية.
- [x] نشر ملف التحقق وإثبات الملكية في Search Console يوم ١٥ نوفمبر ٢٠٢٦. يظل الملف منشورًا لاستمرار التحقق.
- [x] تقديم `sitemap.xml` وفحص حالة فهرسة `/ar` و`/en`. جوجل سجّل الصفحتين كعناوين غير معروفة له وقت الفحص.
- [x] تشغيل Test Live URL في Search Console للصفحتين. جوجل أكد إمكانية الوصول للصفحتين وإمكانية فهرستهما.
- [x] فحص عنوان `sitemap.xml` مباشرة بأداة Test Live URL يوم ١٦ نوفمبر. جوجل أكد أن الزحف مسموح وأن جلب الملف نجح. الخريطة المنشورة تحتوي على ٨ صفحات وروابط صور الكوتش.
- [ ] متابعة تقرير Sitemaps. أعدنا تقديم الخريطة بعد النشر يوم ١٦ نوفمبر. التقديم اتقبل لكن التقرير ظل على «Couldn't fetch» وصفر صفحات مكتشفة وقت الفحص.
- [x] إعادة محاولة طلب فهرسة `/ar` و`/en` يوم ١٦ نوفمبر. كان الرابطان غير معروفين لفهرس Google، والطلبان توقفا عند «Quota exceeded».
- [ ] إعادة طلب فهرسة الصفحة الرئيسية عند تجدد حصة Search Console. أول علامة على التقدم هي ظهور «URL is on Google» لأي صفحة من صفحتي الخدمة.

## محتوى الموقع والروابط

- [x] إضافة اسم الكوتش الكامل وخدمة التدريب الأونلاين في مصر لعنوان البحث ووصف الصفحة باللغتين.
- [x] توضيح خطة التمرين والتغذية وخيار المتابعة اليومية في وصف الخدمة أول الصفحة.
- [x] التحقق من نشر العناوين الجديدة على الرابط الرسمي باللغتين. نجحت فحوص lint وtypecheck والاختبارات والبناء واختبار العرض على الموبايل والكمبيوتر.
- [x] التحقق من وجود الرابط الرسمي في بايو إنستجرام. الرابط موجود وبيشير للنطاق المنشور.
- [x] توضيح خدمة تدريب اللياقة أونلاين في مصر في عنوان قسم الخدمة والنص المقروء على الصفحتين.
- [x] ربط الخدمة واسم الكوتش وحساباته الرسمية بصورته الفعلية في البيانات المنظمة. الصورة الأساسية موجودة في معاينة المشاركة وخريطة الموقع، مع السماح بالمصغرات الكبيرة.
- [x] ربط مدخل النطاق بالعنوان الأساسي للصفحة اللي بيفتحها تلقائيًا للزوار الجدد.
- [x] إضافة دليل عام بعنوان «أسعار التدريب الأونلاين في مصر» يوضح الأسعار الفعلية والفرق بين الباقات وخطوات الاشتراك. الدليل مرتبط من الصفحة الرئيسية ومضاف لخريطة الموقع، والأسعار تستخدم نفس بيانات الباقات.
- [ ] بعد ظهور بيانات البحث، اختبر العبارات اللي بتجيب ظهورًا للدليل وحدد منها الموضوع التالي. العبارات المبدئية هي «كوتش لياقة أونلاين في مصر»، «تدريب أونلاين مع نظام تغذية» و«أسعار التدريب الأونلاين في مصر».

## قياس النتيجة

- [ ] تسجيل أول قراءة متاحة من Search Console للظهور والنقرات ومتوسط الترتيب من مصر. التقرير لسه بيعالج البيانات. بعد ظهورها، تابع العبارات باسم الكوتش وعبارات الخدمة أسبوعيًا.
- [x] إعادة اختبار جوجل في ١٦ نوفمبر. رابط الموقع غاب عن الصفحة الأولى في «كوتش أونلاين في مصر»، «مدرب أونلاين في مصر»، «كابتن أونلاين»، «مدرب أونلاين» و«عبدالرحمن محفوظ كوتش أونلاين». رابط الموقع غاب عن عينة الترشيحات الجديدة على ChatGPT.
- [x] اختبار ChatGPT بالاسم يوم ١٦ نوفمبر. الرد قدّم رابط الموقع الرسمي ورابط صورة الكوتش من الموقع، لكن معاينة الصورة داخل الرد لم تظهر بشكل موثوق.
- [ ] بعد تسجيل الفهرسة، إعادة نفس الاختبار على Google وChatGPT وتسجيل ظهور النطاق في أي من اللغتين ومصدر الصورة لو ظهرت.

سؤال قياس الترشيحات: «ابحث على الويب ورشح لي ٣ مواقع لمدربين لياقة بدنية أونلاين في مصر بيقدموا خطة تمرين وتغذية شخصية، وحط رابط كل موقع رسمي».


## متابعة ١٨ نوفمبر ٢٠٢٦

- [x] فحص Search Console مباشرة: `/ar` و`/en` يعرضان «URL is not on Google» و«URL is unknown to Google»، ولا توجد زيارة زحف مسجلة.
- [x] فحص تقرير Sitemaps: `/sitemap.xml` المقدم في ١٦ نوفمبر لا يزال «Couldn't fetch»، النوع Unknown، وصفر صفحات مكتشفة. السبب الجذري غير مثبت.
- [x] فحص HTTP للنسخة المنشورة: `/` و`/ar` و`/en` و`/robots.txt` و`/sitemap.xml` ترجع 200. الخريطة الحالية تحتوي على ١٠ روابط، بما فيها دليل الأسعار باللغتين.
- [x] فحص metadata وcanonical وhreflang وبيانات Person/Service المنظمة المنشورة: موجودة، ولا يوجد noindex في رؤوس الاستجابة أو metadata للصفحتين.
- [x] فحص جوجل مصر لعبارة «عبدالرحمن محفوظ كوتش أونلاين»: رابط الموقع غائب من أول صفحة في العينة المرئية. لا تعمم النتيجة على كل المستخدمين أو العبارات.
- [x] رصد `/ar` في أداة Web Search المدمجة في الجلسة. المحرك الخلفي غير معلن؛ هذه ليست شهادة بظهور الموقع في Google أو قائمة ترشيحات ChatGPT/Gemini.
- [x] تأكيد أن الدخول الجديد عربي بالفعل؛ تفضيل اللغة المحفوظ يُحترم. `x-default` يشير للإنجليزي، وهو fallback مستقل؛ لم يثبت أنه سبب غياب الفهرسة.
- [x] إضافة الكلمات التي طلبها المالك إلى النصوص والعناوين والدليل في المصدر باللغتين؛ راجع التقرير لمعرفة مواضعها. لا نشر ضمن هذا الفحص.
- [ ] بعد نشر التعديل، تحقق من النصوص على النطاق الرسمي، ثم افحص قراءة الخريطة واطلب الفهرسة عند توافر الحصة. لا تكرر الطلبات باعتبارها وسيلة تسريع.
- [ ] إذا استمر فشل الخريطة: قارن Test Live URL للملف مع تقريره، وافحص سجلات Cloudflare وإعدادات حظر البوتات بحثًا عن طلبات Googlebot الموثقة؛ لا تعطل الحماية بناءً على تخمين.
- [ ] سجل أول «URL is on Google»، ثم impressions/clicks/query/page/country/date من تقرير الأداء. قياس الترتيب يبدأ بعد الفهرسة.
- [ ] اختبر الترشيح العام بصورة مستقلة على ChatGPT وGemini وClaude مع بحث الويب، وسجل السؤال والتاريخ والروابط. لم تُنفذ هذه الاختبارات في جلسة ١٨ نوفمبر.

- [x] اختبار Google Test Live URL جديد للخريطة في ١٨ نوفمبر الساعة ٢٠:١٦:٥٣ بتوقيت القاهرة: الزحف مسموح، الجلب Successful، والفهرسة مسموحة، بواسطة Google Inspection Tool smartphone. نجاح الاختبار لا يعني نجاح معالجة الخريطة المقدمة أو فهرسة صفحات الموقع.
- [x] مراجعة Cloudflare مباشرة: المشروع Production من main، والعنوان SITE_URL صحيح، والنشر التلقائي مفعل. لم تتغير أي إعدادات.


## تنفيذ النشر والمتابعة — ١٨ نوفمبر ٢٠٢٦

الحالة الأحدث لكل بند وما يمكن إصلاحه وما ينتظر جهة أخرى موجودة في [سجل التنفيذ](SEO_GEO_EXECUTION_2026-11-18.md).

- [x] دفع تغييرات الكلمات والخطة إلى main في commit 93ac9e6، ونجاح Cloudflare Pages، والتحقق من النصوص المنشورة في الرئيسية والدليل باللغتين.
- [x] فحص HTTP للصفحات العشر، والعناوين وcanonical وربط اللغات و٥٢ مرجعًا داخليًا؛ لا منع فهرسة أو رابط مكسور مثبت بعد متابعة انقطاع الصورة العابر.
- [x] إضافة ٤ اختبارات إعدادات بحث وتشغيل ٩ اختبارات وحدة بنجاح، مع مرور lint وtypecheck والبناء بعد تحسين مسافات العنوان الرئيسي.
- [ ] متابعة تقرير الخريطة وطلبات الفهرسة من حساب جوجل: اتصال Chrome غير متاح للأداة في هذه الجولة، ولم يُنفذ تقديم جديد.
- [ ] قياس السرعة: PageSpeed API رجع 429 بسبب الحصة اليومية. موعد إعادة المحاولة المتوقع ١٩ نوفمبر الساعة ١٠ صباحًا القاهرة، حسب قاعدة Google Cloud العامة؛ لا ضمان بإتاحة الحصة وقتها.

- [x] نشر تحسين مسافات العنوان والاختبارات في commit c23622e، ونجاح Cloudflare Pages، ثم التحقق من العنوانين كاملين في HTML العام. تحويلات HTTP/HTTPS والشرطة النهائية وعنوان canonical لمعاملات الحملات سليمة في العينات المفحوصة.
