# Social media and presentation layouts

Design for the platform's current canvas and safe areas; dimensions change, so the enduring rules are hierarchy and readability. Keep a single main idea per frame. Use editorial crops, strong typographic hierarchy, generous negative space, a quiet grid, and orange only for action or emphasis. Green denotes actual progress/function. Keep logo small and consistent.

- **Instagram/Facebook posts:** one headline or proof point, one image, minimal metadata. Transformation photos follow `BEFORE_AFTER.md`.
- **Stories/Reels/TikTok/Shorts:** vertical safe zones; face and essential information clear of interface chrome; captions native to Arabic/English; restrained cuts.
- **YouTube thumbnails:** one focal subject, very short readable copy, high contrast; no fake shock, claim or result.
- **LinkedIn:** if used, apply a measured expertise tone with the same palette and type; avoid inventing a corporate sub-brand.
- **Presentations/PDFs:** stable title/body/caption hierarchy, ample margins, small footer mark, accessible contrast and legible tables. Charts use neutral series; orange highlights one key series, green only when semantically meaningful.

Do not stretch one layout to every ratio. Re-compose while preserving type, palette, geometry and image integrity. Do not use client proof without approved privacy-safe source assets.
