# Light and dark modes

Both are first-class. Dark is the website's default, not a different brand. Use semantic variables such as `--ma-background`, `--ma-surface`, `--ma-text`, `--ma-brand` and `--ma-performance`; see `css/brand.css`.

Dark mode uses black/navy foundations, off-white foreground and muted blue-gray secondary copy. Light mode uses cool pale gray-blue surfaces, dark blue-gray text, darker orange/green text accents, and subtle shadows. Keep action orange and brand roles consistent. Preserve contrast in both modes. Avoid pure inversion, unreadable muted copy, or forcing dark text on the established dark chapter sections.

For the portable CSS, add `data-brand-theme="light"` to the root. Omit or set `dark` for dark mode.
