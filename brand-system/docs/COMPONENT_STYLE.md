# Component style

- Buttons: orange primary with dark text; quiet outline secondary; clear hover, active, focus, and disabled states. Minimum 44px target.
- Cards: square/4px corners, hairline border, navy or neutral surface. Use elevation sparingly; do not make every section a floating card.
- Inputs: clear label, visible boundary, readable placeholder, error text and keyboard focus. Never collect data outside the product's approved purpose.
- Badges: compact uppercase utility labels, not rating or scarcity devices.
- Icons: consistent outline set, 1.75–2px stroke; pair meaning with text.
- Images: rectangular by default, native aspect ratio when truth matters.
- Layout: clear content alignment, generous breathing room and predictable focus order.
