# Accessibility

- Target WCAG 2.2 AA: 4.5:1 normal text, 3:1 large text and meaningful UI boundaries.
- Keep visible keyboard focus, logical source order, semantic landmarks and native controls.
- Target 44×44px touch controls; don't rely on hover.
- Maintain readability at 200% zoom and narrow reflow; avoid clipping Arabic headings.
- Use `lang` and `dir` correctly, logical CSS properties, and direction isolation for mixed-script data.
- Pair status colors with labels/icons. Provide meaningful alt text; decorative imagery uses empty alt.
- Respect reduced motion and don't communicate state through motion alone.
- Check both themes and real image backgrounds. An intentional brand color is not exempt from contrast requirements.
